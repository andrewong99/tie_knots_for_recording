# 结绳记事 jiesheng.py

一条横绳（太极）在上，纵绳往下垂。Python 3 + tkinter，无第三方依赖。

- 执行：`python jiesheng.py`
- 自检：`python jiesheng.py --selftest`（目前 519 项）

---

## 原理（读绳的人只要记住这几条）

| | |
|---|---|
| 结在横绳上 | 换栏位。栏位顺序由左到右，自己排 |
| 一股一结 | 阳 |
| 分两股两结 | 阴 |
| 爻序 | 最靠近横绳的是**上爻**，最下面是**初爻** |
| 三结 | 一个八卦 |
| 六结 | 一个六十四卦，卦名照**先天方图卦序** |
| 计数绳 | 由上而下＝高位到低位，一位打几结就是几 |
| **零** | **一个大横结，不留空白** |
| 支绳 | 只从**右边**接出去，可以一层层往下串，读作「这个的那个」 |
| 分段绳 | 横绳上一个结 ＋ 一条超长虚线。古人省绳子只打横结，虚线只是给眼睛看的 |
| 横绳上的结 | 只是普通一个结，不是阳结 |

栏位次序：卦年｜卦期｜卦月｜卦日｜卦时｜方位·地点｜人｜事情｜数量·能量级别（顺序固定，见〈绳子结构校验码〉）。
一个栏位可以连着好几条绳 —— 乾为天（天朝）＋ 兑为泽（羊）＝ 天羊国。

卦年一轮六十四年；是哪一轮不写在绳上，靠人记得。
超过一万，绳子不够用 —— 该造字了。

## 纵绳与结

- **分段绳**　横结 ＋ 超长虚线
- **三爻绳**　三个阴阳结 ＝ 一个八卦
- **六爻绳**　六个阴阳结 ＝ 一个六十四卦
- **十进制绳**　位值制，十进一。十五 ＝ `十位1结｜阳结｜个位5结`。大数用它（3979、66、20…）
  另有「每位四个阴阳结」的二进制打法可选（设定选单）。
  一位一条绳也行（3979 排成四条 3／9／7／9），程式两种都读
- **十天干绳**　十位的**循环**，一位一个结：甲1 乙2 丙3 丁4 戊5 己6 庚7 辛8 壬9 **癸＝10 结**
- **十二地支绳**　十二位的**循环**，一位一个结：子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 **亥＝12 结**
- **大横结**　零（三个结宽）
- **分位阳结**　一个数字里位与位之间的分隔点（两个结宽）
- **分割横结**　栏位与栏位之间的定界符，横绳上一个普通结

两种循环绳**都不是位值制** —— 没有进位，也没有零。
对照：十进制的 10 是 `1｜阳结｜大横结`，天干绳的 10（癸）就是**十个结**。

## 绳子结构校验码

栏位顺序是固定的：**年 月 日 时 → 天（方位）地（地点）人 → 事情 → 数量**。

这个顺序本身就是校验码。从垃圾堆里捡一串绳出来：

- 年没有那么小 —— 不会读成「1 年、25 年」
- 掉转过来读，顺序全反了，读不通
- 数量在最后而且是小数 —— 不会被读成 397912

**栏位与栏位之间打一个分割横结**，年到哪里为止就没得争。
没有它，`3979｜12` 跟 `39791｜2` 在绳上长得一模一样。

**绳串没有正反面**，所以正反全靠顺序定，而且**不必标栏位也验得了**：

- 头一栏一定是数，而且不会小（年没有那么小）
- 第二、三栏若是数，不会超过 12 个月、31 日

倒过来读，头一栏就变成卦象或小数，立刻穿帮。
例：`3908年癸丑月…获得23头牛` 倒过来就成了「年＝坤为地，…，末栏＝8093」。

下面第三页 **严谨检查** 把会读错的地方全列出来（顺序／值域／该补／提醒），
双击一行就地补一个分割横结；工具 → **倒读验证** 把整串绳反过来读给你看，
还会直接写出「倒过来会读成：年＝… 月＝… 末栏＝…」。
正读通、倒读不通，校验码才算立得住。

检查的几条规矩：

| 级别 | 抓什么 |
|---|---|
| 顺序 | 栏位顺序反了；开头不是卦年；结尾不是数量 |
| 值域 | 月>12、日>31、时>12、期>64；卦年小于 13（年没有那么小） |
| 该补 | 换了栏位却没打横结 —— 3979｜12 与 39791｜2 就是这样分不出来的 |
| 提醒 | 两条三爻绳并排会连读成一个六爻卦；整册都没标栏位（顺序验不了） |

**相邻的计数绳 ＝ 同一个数的各位**：`3｜9｜7｜9` 读作 3979，`1｜3` 读作 13。
十进制、天干、地支都一样 —— 绳上看，一条几个结的绳就是几个结。
断在哪里靠后面那个横结，所以并排不是错，少了横结才是。
**单独一条**（两边都有横结）才读成干支的那一位：`12·亥` ＝ 亥时。
**天干绳紧接着地支绳 ＝ 一对干支**：癸 ＋ 丑 ＝ **癸丑**，不是 102。
中间要是打了横结，干支就被拆成两栏了 —— 严谨检查会抓出来，
双击那一行就把中间那个横结拿掉。
大横结夹在数中间算 0。释读会自动并读。

一位数的十进制绳跟同值的天干绳在绳上是同一串结（3 就是三个结），
所以两者都注干名。两位以上不注 —— 十进制的 10 是 `1｜分位｜大横结` 只有三个结，
跟天干癸的十个结不是一回事。

## 卦绳的底层画法：一条绳对折挂上去

**顶上两股，底下也两股。** 中间每一爻：

- **阳** ＝ 两股收拢绑死，**闭合，穿不过去**（一画开天）
- **阴** ＝ 两股各走各的，中间留着洞，**穿得过去**

两股平时是张开的，只有走到一个爻上才收拢或维持 ——
所以全阳的**乾是一串闭合的环**，全阴的**坤是一条通到底的道**。
绳尾两股散开，不收成一点。计数绳（十进制／天干／地支）是**单股**，没有这回事。

## 右接

支绳系在母绳的**绳尾**上，只系右边 ——
卦绳尾巴散开成两条，就系右边那条；计数绳单股，就系它那一条。
母绳是什么绳都行（例三就是「六六→乾为天→坤为地」），
**受限的是支绳自己：右边接出去那条一定是卦绳**（三爻或六爻）。
十进制、天干、地支、大横结、分位、分割一律挂在横绳上，不当支绳。

**右接是修饰，不是并列**：天右接雷 ＝ 天的雷（雷从天上来），读成一样东西。
释读写成 `乾为天→震为雷`，跟旁边那条绳的「，」分得开。

## 结的尺寸阶梯

三种宽度，三种意思，不会混：

| 宽度 | 是什么 |
|---|---|
| **一个结** | 半个阴爻。阴爻就是两个这样的结，并排、不连在一起。计数结也是这个 |
| **两个结** | 阳结 —— 两个阴爻结绑在一起（或一条绳绑两次），宽一点 |
| **三个结** | 大横结 ＝ 零。最大 |

**位与位之间打一个阳结，绝不留空白**：

- 12 ＝ 1｜阳结｜2
- 3979 ＝ 3｜阳结｜9｜阳结｜7｜阳结｜9

中间留一段空白，谁也分不清是几位。同理零留空白，别人分不出
是绳编长了还是零 —— 就跟阴爻不能留空一样，两边都要打结，只是不连在一起。

**分割** 是另一回事：横绳上一个普通结而已，底下不挂东西，
跟大横结不是同一个结（例：3979 那条年绳后面挂一条，人家就知道年写完了）。

分位阳结、大横结、分割 三个都能从右边面板拖出来单用。

## 字要不要显示，自己打勾

检视 → **显示哪些字**：数值·天干（3·丙）／带不带天干／位值注记（3（个位））／
卦名／方图序号／爻位／旁注／栏位标签／「横结」二字。
预设只留数值、卦名、爻位、旁注 —— 栏位标签与位值注记**预设关掉**，绳子才收得紧。
「全关」剩下纯绳与结。

画布上那些 `!`／`?` 检查记号**预设关掉**（在「显示哪些字」里勾回来）——
检查本身照跑，结果都在下面第三页。

检视 → **阴阳结距**、**计数结距**、**列距（两条绳之间）** 三套各四档，分开调。
列距预设**极窄**（两栏的字之间不再多留空），嫌挤就往上调。
3979 那种长数字绳把计数结距切到「极密」；绳子挤不下就把列距放宽。
预设：阴阳 32 ／ 计数 15 ／ 列距 0（极窄）。

## 操作

- 右边面板**按住往左拖**。落点规则：
  **横绳上下这一带一律挂横绳** —— 会画一个插入箭头，告诉你插进第几位，
  旁边的绳自动让开；要右接，拖到绳身中段。空白处也是挂横绳。
  双击面板＝加到最右边
- 现成的绳也能拖：拖回横绳一带就脱钩变根绳，拖到别条绳身上就变它的支绳
- **换绳型不必删掉重拖**：右键 →「换成…」，或右边属性栏的「换成」。
  旁注、栏位、右接的支绳全部留着；三爻↔六爻时留着的爻当下卦
- **点结**＝阴阳互换（预设全阴）
- **拖一条计数绳过去，数字输入框直接跳出来**，不必再点一次
- **改数字**：点绳尾那个数字（例如「9·壬」），就地跳出输入框 —— 打新数字，
  Enter 或点外面存起来，Esc 放弃。双击绳身也开。右边属性栏也能直接输入。
  结本身点了不会改数字，滚轮也不会（免得手一滑就改掉）
- 右键绳身：右接、全阳、全阴、错卦、左右移、删除
- Ctrl+Z / Ctrl+Y 复原重做（换记录也复原得回来）
- 编辑 →「清掉这条横绳的所有栏位标签」：旧版给新绳猜过预设栏位，
  那些假标签会把顺序检查判成一堆错，清掉再自己标
- 右边面板拉得长，自己有卷轴，滚轮在面板上就卷面板
- 万一开起来只剩下面那三页、画布和右边面板不见了：**检视 → 版面复位**。
  程式开机后两秒内也会自己回头看三次，压扁了就摆回来

## 记录册

一个档案可以放很多条横绳，每条横绳一笔记录。

- 上面那排：◀ ▶（或 PageUp/PageDown）翻、改名、＋新横绳、删这条
- **翻记录／检索**（Ctrl+F）把整册压成一行一行，打字就筛 ——
  卦名、上下卦、数字、天干、栏位、旁注都能找

> 老智者死了，二十几岁的新智者只要知道原理，四十年前的绳子照样读得懂。
> 这一页就是那本册子。

## 下面四页

- **释读**　一句话读法，同栏位的绳会合并，相邻的十进制绳自动并成一个数
- **全面注解**　逐条列出卦象、上下卦、说卦的人伦／动物／身体／方位／五行／广象，以及你的旁注
- **严谨检查**　校验码（见上）
- **我的注释**　★ 自己手写，**跟着档案一起存**

前三页是程式每次重画就重写的，所以是**只读**的 —— 在那上面打字，下一次重画就没了。
要自己写字，写在「我的注释」。每条绳旁边的**旁注**（右边属性栏那格）也是存得住的。

## 卦名出处

六十四卦名与次序 **照抄 `guaxu_core.FANG_TU`**（自定义的先天方图卦序，
上卦为纲、下卦为目，两者都走先天序 乾兑离震巽坎艮坤）。
自检里 192 项逐格核对 `上卦×8＋下卦＝方图序号`。
Unicode 卦符 ䷀–䷿ 另经周易序映射取得，只用来显示符号。

## 完备性

绳子怎么编、怎么摆，意思都不该跑 —— 反着看、横着看、竖着看，
编制距离宽了窄了，绳子什么颜色，大了小了，意思都一样。会跑的只有人的诠释。

支撑这句话的三条硬规矩：

1. **阴一定要打结**，不能因为它是阴就空着 ——
   空着，别人分不出是阴还是这一段还没写。（跟零要打大横结同一个道理）
2. **六十四卦不重不漏**，刚好盖满方图，所以六个结位一定读得出唯一一卦
3. **栏位顺序固定**（年月日时 → 天地人 → 事情 → 数量），所以掉转过来读不通

`--selftest` 的 Q 节验第 1、2 条：每一爻都在，全阴的坤照样是三层／六层而不是空绳，
六十四卦互不重复、刚好盖满方图，零也一定打大横结。

## 记什么用什么

| 记什么 | 用什么 |
|---|---|
| 时间、名字、数量 | 天干（十位循环）／地支（十二位循环）／十进制（位值制） |
| 形容东西 | 卦象 |

**人名 ＝ 卦象（氏）＋ 数字（名）**：两个横结之间放「水地比 ＋ 88」，
就是 **小川 88** —— 水在地上是小川（氏），88 是名。
朱重八本名朱八八，父朱五四，祖朱初一，曾祖朱四九，高祖朱百六，同一路数。
释读与全面注解会自动把人这一栏读成「氏＝… 名＝…」。
